# FEA-005: Activity Views and Insights

## Outcome
Users can review recent activity, browse their full history, and understand time spent across media types.

## Scope
- Dashboard showing the last 7 days and quick stats.
- Full chronological history timeline.
- Music grouping and HTMX pagination for dense history days.
- Stats page with time breakdowns, charts, top items, and period filters.

## Dependencies
- FEA-002 provides log retrieval and grouping.
- FEA-004 provides the shared layout and design conventions.
