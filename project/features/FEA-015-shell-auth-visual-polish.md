# FEA-015: Shell and Authentication Visual Polish

## Outcome
The application has a more legible visual identity and a deliberate mobile and sign-in experience.

## Scope
- Replace Syne with a less compressed display typeface that retains the existing bold editorial character.
- Apply the typography change consistently across shared UI chrome and headings.
- Add prominent STrackerr identity to the login page without turning it into a marketing page.
- Improve the mobile navigation drawer with a close control and clearer section separation.

## Dependencies
- Completed MVP app shell, authentication views, responsive navigation, and design system.

## UX Requirements
- Typography remains readable at current sizes in both themes and across supported breakpoints.
- The mobile drawer has an accessible name, keyboard-operable close control, focus handling, and clear grouping for primary, admin, and account actions.
- Login retains a direct path to authentication with the app name visible in the first viewport.
